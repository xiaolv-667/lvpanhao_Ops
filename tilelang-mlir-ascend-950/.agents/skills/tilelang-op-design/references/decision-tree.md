# 算子特征分析决策树

## 1. 函数设计原则

维度从输入 shape 或函数参数取得，不依赖会污染顺序测试的全局状态。Host 预处理在算法和数据流中显式声明。

## 2. 计算路径选择

- 矩阵计算：按平台矩阵编程指南选择计算单元、模式、布局与搬运。
- 逐元素计算：按平台选择向量 API 或线程并行表达式。
- 归约计算：按平台核对归约原语、累加类型和核内/跨核结构。
- 混合与融合：按平台核对计算单元协作、流水线及同步支持。
- 其他复杂算子：先检索当前平台兼容的例子，再设计最小实现。

## 3. 资源约束

以任务型号预算和 ruleset 的对齐、分形、动态边界及容量要求核验候选。具体参数不由通用决策树规定。

## 4. API 映射

按 ruleset 的语言模块与证据入口核对导出、签名、模式和语义；采用平台核验可用的写法。§3.1 以 §1.6.1 的公式为输入，§6 与 §1.6.2 的并行化结论一致。
